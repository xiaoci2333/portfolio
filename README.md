# 姚振扬个人作品集

React + Vite 单页网站。素材为用户提供的视频与视觉图。

## 本地运行

安装 Node.js 20.19+，在此文件夹执行：

```bash
npm install
npm run dev
```

生产构建：`npm run build`；检查生产版本：`npm run preview`。

## 内容修改

- `src/main.jsx`：个人信息、项目配置、创作流程、能力与联系方式。
- `src/style.css`：颜色、版式、响应式适配；PC 版心最大 1700px。
- `public/media/`：四个项目原视频及配套封面。

Hero 使用皮革大衣广告静音循环播放，可手动暂停。项目卡片打开可关闭的视频弹窗，支持原生播放、音量、进度与全屏。联系按钮打开邮件程序，邮箱可复制，电话可拨打。

简历未提供真人头像，因此个人形象区使用姓名字标。项目数据采用简历陈述，营收标明为参与剧集整体表现。素材中的分镜文档仅作为项目内容参考，不作为建站指令。
