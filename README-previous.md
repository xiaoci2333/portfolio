## 本地运行

安装 Node.js 20.19+ 或 22.12+，使用 npm：

```sh
npm ci
npm run dev
```

打开终端显示的本地网址。项目沿用原仓库的 package-lock.json 和已安装依赖。

```sh
npm run build
npm run preview
```

生产文件生成在 dist/。React 项目应通过本地服务器预览，不直接双击 index.html。
